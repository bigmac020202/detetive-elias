# Detetive Elias

Site oficial de **Detetive Elias 2: A Ordem da Pedra** (3D, campanha e multijogador online) e do
**Detetive Elias 1: Remake** — os dois de graça, pelo **Detetive Elias Launcher** (Windows).

- Lançamento: **27/09/2026 às 14:30** (horário de Brasília)
- Download: aba **Releases** deste repositório (instalador do launcher e os pacotes dos jogos)

O launcher e os jogos não usam servidor nem conta: o multijogador conecta direto entre os jogadores
(UPnP/IPv6, com VPN grátis como reserva).
